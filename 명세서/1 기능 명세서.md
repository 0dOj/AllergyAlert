## 화면별 기능

### 스캔 화면

- 웹캠 뷰파인더, 스캔 가이드 프레임
- 바코드 번호 수동 입력 필드
- 카메라 권한 거부 시 안내 + 수동 입력 전환
- 스캔 성공 → 결과 화면 이동

### 결과 화면

- 판정 배지 (위험 / 주의 / 안전)
- 걸린 알레르겐 목록 + 매칭된 원재료 문구
- 원재료 전문 (매칭 부분 하이라이트)
- 제품명 · 제조사 · 식품유형 · (소비기한)
- 생산중단·폐업 제품이면 안내 배너
- 법적 고지

### 프로필 화면

- 알레르겐 체크박스 19개 항목
- 조개류는 굴·전복·홍합 개별 선택
- 사용자 정의 알레르겐 추가 (선택)

### 이력 화면

- 최근 조회 목록 (제품명 · 판정 · 일시)
- 항목 클릭 → 결과 재표시
- 개별 삭제

## 기능별 수용 기준 (Acceptance Criteria)

> 기능 목록만으로는 두 사람이 같은 기능을 다르게 구현한다. 아래 기준을 충족해야 "완료"다.
> 

### F-01 바코드 카메라 스캔

- 후면 카메라(`facingMode: environment`)로 실행된다
- EAN-13 바코드를 3초 이내에 인식한다n- 같은 바코드를 2초 내에 재인식하면 무시한다
- 페이지를 떠나면 카메라 스트림이 정리된다 (`track.stop()`)
- 권한 거부 시 에러 화면이 아니라 수동 입력으로 전환된다

### F-02 바코드 수동 입력

- 8~14자리 숫자만 허용
- 길이 미달 시 조회 버튼 비활성
- 카메라 미지원 환경에서도 항상 노출

### F-03 제품 조회

- C005 → I2570 순서로 조회한다
- 둘 다 없으면 404와 함께 `fallback: search_by_name`을 반환한다
- `END_DT` 또는 `CLSBIZ_DT`가 있으면 `discontinued: true`
- 응답에 어느 소스에서 찾았는지(`source`)를 포함한다

### F-04 제품명 검색

- 2글자 이상부터 검색된다
- 부분 일치(`LIKE`)로 최대 20건 반환
- 결과 0건도 200으로 빈 배열을 반환한다 (404 아님)

### F-05 원재료 조회

- 쉼표 연결형·row 분리형 응답을 모두 동일한 문자열로 정규화한다
- row가 여러 개면 `RAWMTRL_ORDNO` 오름차순으로 정렬 후 결합
- 원재료가 없으면 예외가 아니라 빈 문자열 + `caution`

### F-06 알레르기 판정

- `danger` / `caution` / `safe` 중 하나를 반환
- 직접 매칭이 있으면 복합원재료 유무와 무관하게 `danger`
- 원재료가 없거나 복합원재료가 있으면 `caution`
- 프로필이 비어 있으면 400과 함께 프로필 설정을 유도
- 동일 알레르겐이 여러 번 매칭되어도 목록에는 1회만

### F-07 매칭 근거 표시

- 응답의 `matched[].start` / `end`로 해당 구간만 강조한다
- 구간이 겹치면 병합해서 렌더한다
- 색상만으로 구분하지 않고 아이콘·텍스트를 병기한다

### F-08 알레르겐 프로필

- 19개 법정 항목을 체크박스로 제공
- 조개류는 굴·전복·홍합을 개별 선택 가능
- 저장 후 새로고침해도 유지된다

### F-10 조회 이력

- 최근순 정렬, 최대 50건
- 항목 클릭 시 저장된 판정 결과를 그대로 재표시 (재계산 아님)
- 개별 삭제 가능

### F-11 법적 고지

- 결과 화면 하단에 항상 노출. 닫기 불가

### F-12 야간 배치

- `--service` / `--mode` / `--dry-run` 옵션 지원
- `INFO-110`, `ERROR-503`, `INFO-200`을 구분해 사람이 읽을 메시지로 종료
- `ingest_log`에 실행 이력 기록
- 순차 호출 (동시 요청 금지)
